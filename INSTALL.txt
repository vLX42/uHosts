uHosts — minimal /etc/hosts editor for Apple Silicon Macs
==========================================================

1. Drag uHosts.app into your /Applications folder.

2. macOS will refuse to open this app on first launch because it
   isn't notarized by Apple (notarization requires a paid
   Developer Program membership). Two ways to bypass:

   Option A — Terminal (one command):
       xattr -d com.apple.quarantine /Applications/uHosts.app

   Option B — Finder:
       Right-click uHosts.app → Open → click "Open" in the dialog.

   You only need to do this once.

3. Look for the network icon in your menu bar (top-right).
   Click it to open uHosts.

4. The first time you click "Apply", macOS will prompt for your
   admin password. This is required to write to /etc/hosts.
   Subsequent applies in the same session may not re-prompt.

Requirements
------------
- macOS 14 (Sonoma) or later
- Apple Silicon (M1/M2/M3/M4)

What it does
------------
- Lists entries from your existing /etc/hosts.
- Toggle each entry on/off with a switch.
- Add or remove entries, then click Apply.
- Backs up your original /etc/hosts to
  ~/Library/Application Support/uHosts/hosts.backup-original
  before the first write.

Uninstall
---------
1. Quit uHosts (click the power icon in the popover, or:
   killall uHosts)
2. rm -rf /Applications/uHosts.app
3. rm -rf ~/Library/Application\ Support/uHosts
4. If you want to restore /etc/hosts to its pre-uHosts state,
   the backup is at the path above.
