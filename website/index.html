Install

  1. Download the latest release.
    A single zip with the app and an INSTALL.txt.
  2. Drag uHosts.app into your /Applications folder.
  3. Bypass Gatekeeper. This build isn't notarized by Apple (notarization requires a paid Developer Program membership). 
    $ xattr -d com.apple.quarantine /Applications/uHosts.app
    Or: right-click the app in Finder → Open → click Open in the dialog. You only need to do this once.
  4. Use it. Click the network icon in your menu bar. The first Apply prompts for your admin password — that's macOS asking for permission to write to /etc/hosts.

What it does

  • Toggle hosts on/off with a switch
  • Imports your existing /etc/hosts on first launch
  • Backs up the original before the first write
  • Lives in the menu bar, no Dock icon
  • Compatible with iHosts (standard hosts format)
  • SwiftUI + AppKit, no Electron, no web view

Requirements

  • macOS 14 (Sonoma) or later
  • Apple Silicon (M1 / M2 / M3 / M4)

Why a clone?

The original iHosts doesn't ship a native Apple Silicon build. uHosts is a minimal rewrite: read existing entries, toggle, apply. No schemes, no cloud sync, no telemetry — just a switch and an apply button.
